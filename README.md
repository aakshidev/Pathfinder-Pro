# 🚀 Pathfinder Pro — AI-Powered College Planning Platform

> Personalized college planning, career discovery, and application strategy — powered by AI.

---

## 🌟 Overview

Pathfinder Pro helps students transform academic profiles, goals, and interests into an actionable roadmap for university admissions.

Instead of generic recommendations, Pathfinder Pro generates:

- 🎯 Personalized college recommendations  
- 🧠 AI-powered career exploration  
- 📄 Resume-informed evaluation  
- 🛣️ Custom roadmap & next steps  
- ✨ Dream university fit analysis  

Built as a hackathon project to make admissions planning more accessible and personalized.

---

## ✨ Features

### 🎓 Smart College Matching
Generate university recommendations based on:
- Academic profile
- Intended major
- Budget
- Preferred location
- Resume score
- Dream universities

### 🧠 AI Career Suggestions
Discover career paths aligned with:
- Skills
- Interests
- Academic strengths

### 📄 Resume Insights
Upload a resume and receive:
- Academic evaluation
- Leadership assessment
- Project strength score
- Overall profile rating

### 🛣️ Personalized Roadmap
Get:
- Monthly milestones
- Improvement suggestions
- Application strategy

### 💭 Dream University Analysis
Evaluate:
- Fit
- Competitiveness
- Gaps to improve

## ⚙️ Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Move into project:

```bash
cd pathfinder-pro
```

Install dependencies:

```bash
npm install
```

Create environment variables:

```env
OPENAI_API_KEY=your_api_key
```

Run locally:

```bash
vercel dev
```

Open:

```text
http://localhost:3000
```
